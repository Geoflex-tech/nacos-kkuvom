## How to Add a New Owner
1. Go to the organization page
2. Click **People**
3. Click **Invite member** → enter their GitHub username
4. After they accept, change their role to **Owner**

## Handover Process (End of Administration)
1. Add the incoming president as an Owner
2. Confirm they can access the repository and Vercel
3. Outgoing president steps down to Member
4. Update this document with the new owner list
